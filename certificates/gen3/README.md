The program `verify_gen3.py` is the formal submission checker for the finite one-triangle lemma in the proof of GEN₃ (the bound $S\le 3n$, with equality only for the Petersen graph) in `paper/main.tex`; the audit is the finite-certificate section of `paper/supplement.tex`. It is a Python 3.10+ program that uses only the standard library and embeds the decision certificate. From this directory, run `python3 verify_gen3.py`.
