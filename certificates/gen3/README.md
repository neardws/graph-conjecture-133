The program `verify_gen3.py` is the checker for the two-triangle search in Lemma 5.9 of `paper/main.tex` (the bound $S\le 3n$, with equality only for the Petersen graph, is Theorem 5.10). The audit is Appendix A of that article. The same program still checks an older one-triangle row; the article proves the one-triangle case by hand and does not cite that row. It is a Python 3.10+ program that uses only the standard library and embeds the decision certificate. From this directory, run `python3 verify_gen3.py`.
